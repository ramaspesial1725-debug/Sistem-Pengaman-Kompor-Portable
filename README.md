# Rancang Bangun Sistem Pengaman Otomatis Kebocoran Gas dan Overheat pada Kompor Portable

## Deskripsi
Proyek ini bertujuan membuat sistem keamanan otomatis pada kompor portable menggunakan sensor gas dan sensor suhu.

## Komponen
- Arduino Nano
- MQ-6
- Thermistor NTC
- Servo Motor
- Buzzer
