BAREMETAL PROGRAM C++
ARDUINO MEGA2560 & ESP8266(modul wifi)

Logika Sistem:
Sistem SP3S memonitor kadar gas dan suhu secara real-time menggunakan sensor gas dan DHT, menampilkan data pada LCD serta mengirimkannya melalui UART. Jika kadar gas melebihi 400 atau suhu mencapai 60°C, sistem mengaktifkan buzzer dan indikator bahaya serta menampilkan status "BAHAYA"; jika tidak, sistem menampilkan status "AMAN" dengan indikator normal.
